# LyraDev — Cinematic RTL Studio Website

A self-contained Persian RTL studio landing page.

## Preview locally
Open `index.html` in a browser. The page uses Google Fonts; all layout, styling, animation and interaction code is included in the HTML file.

## Publish with GitHub Pages
The workflow at `.github/workflows/deploy-lyradev.yml` publishes the contents of this folder when changes are pushed to the `lyradev-cinematic-site` branch. In the repository settings, set **Pages → Build and deployment → Source** to **GitHub Actions** if it is not already enabled.

## Before going live
- Replace or verify the testimonial wording and attribution.
- Add the real email / phone / address details if you want them displayed.
- Connect the contact form to a real endpoint (Formspree, your own API, etc.). It currently validates the fields and copies the request text; it does not send messages to a server.
- Replace the CSS-built project mockups with approved project screenshots when available.

No contact details or backend endpoint have been invented.
